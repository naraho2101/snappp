# Snappp prototype

A playable web prototype of Snappp, a habit tracker where every photo you snap plants a flower in your garden.

Open `index.html` through any static server, for example `python3 -m http.server`. There is no build step; the site is plain HTML, CSS and JavaScript, and Netlify publishes this folder as is.

The demo controls beside the phone (or behind the round button on a phone) let you skip days and trigger reminders to try the habit rules.
